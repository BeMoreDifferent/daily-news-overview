Daily News

Use Daily News in your AI assistant

The daily briefings are available through a Model Context Protocol (MCP) server, so assistants such as Claude can read them directly. It is free, read-only and needs no account or API key.

Server URL

https://daily-news-mcp.bemoredifferent.workers.dev/mcp

Claude Code

claude mcp add --transport http daily-news https://daily-news-mcp.bemoredifferent.workers.dev/mcp

Claude.ai and Claude Desktop

Open Settings → Connectors → Add custom connector, enter a name such as "Daily News" and paste the server URL above.

Other MCP clients

Add a remote server with the Streamable HTTP transport and the URL above. A typical JSON configuration: 

{
  "mcpServers": {
    "daily-news": {
      "type": "http",
      "url": "https://daily-news-mcp.bemoredifferent.workers.dev/mcp"
    }
  }
}

Tools

  • get_daily_news — the briefing for a date (YYYY-MM-DD), today by default: overview and up to 15 top stories with their sources. A day's briefing is published the next morning (UTC), so until then you get yesterday's.
  • get_topic — one story of that date in full, with article descriptions, entities and keywords.

Example prompts

  • "What are today's top stories?"
  • "Summarise the news from 1 October 2026."
  • "Tell me more about the second story."

Limits and privacy

Tool calls are limited to 60 per minute per IP address. The server stores no personal data; see the privacy policy for how requests are processed and measured.
