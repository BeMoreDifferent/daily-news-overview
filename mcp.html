Daily News

Use Daily News in your AI assistant

The daily briefings are available through a Model Context Protocol (MCP) server, so assistants such as Claude can read and search them directly. It is free, read-only and needs no account or API key.

Server URL

https://daily-news-mcp.bemoredifferent.workers.dev/mcp

Claude Code

claude mcp add --transport http daily-news https://daily-news-mcp.bemoredifferent.workers.dev/mcp

Claude.ai and Claude Desktop

Open Settings → Connectors → Add custom connector, enter a name such as "Daily News" and paste the server URL above.

Other MCP clients

Add a remote server with the Streamable HTTP transport and the URL above. A typical JSON configuration: 

{
  "mcpServers": {
    "daily-news": {
      "type": "http",
      "url": "https://daily-news-mcp.bemoredifferent.workers.dev/mcp"
    }
  }
}

Tools

  • list_dates — the days for which a briefing exists, newest first.
  • get_daily_news — one day's briefing (the latest if no date is given): overview and up to 15 top stories with their sources.
  • get_topic — one story in full, with article descriptions, entities and keywords.
  • search_news — find stories from the last days (up to 14) that contain all words of a query.

Example prompts

  • "What are today's top stories?"
  • "Summarise yesterday's news about the economy."
  • "Has there been anything about climate policy this week?"

Limits and privacy

Tool calls are limited to 60 per minute per IP address. The server stores no personal data; see the privacy policy for how requests are processed and measured.
